# Features — 오프라인 대응 번역 웹앱(모바일 우선)

본 문서는 제품 출시(Website/PWA) 기준으로 필요한 기능을 정리합니다. 근거 문서: `AGENTS.md` 및 `registry/` 하위 패턴 문서. 외부 링크는 AGENTS.md에 정리되어 있으므로 여기서는 내부 파일 경로만 참조합니다.

## 0) 릴리스 범주

- MVR(최소 출시): 브라우저 내 오프라인 번역, KO↔EN·KO↔JA, PWA 설치, 기본 UX.
- Plus(선택): 온라인 업스케일, 프레이즈북 템플릿 확장, 측정/진단 고도화.

## 1) 번역 코어(클라이언트 추론)

- 모델/토크나이저 로딩
  - 언어 방향별 개별 패키징: `ko→en`, `en→ko`, `ko→ja`, `ja→ko`.
  - 지연 로드 + 백그라운드 프리패치(사용자 선택 시). 진행률/예상 용량 표시.
  - 파이프라인 API 기반 호출(Transformers.js). 디코딩 프리셋: “빠른/정확”.
  - 모델 버전 태깅과 무중단 교체(백그라운드 다운로드 후 스위치).

- 추론 백엔드 선택
  - 기본 `WASM` 실행, `navigator.gpu` 감지 시 `WebGPU` 가속.
  - 실행 EP 상태 배지 표시: `Local · WASM` 또는 `Local · WebGPU`.
  - 실패/불가 시 자동 폴백 및 사용자 알림(성능 차이 안내).

- 문장 제약 및 품질 옵션
  - 입력 길이 제한(예: 200–300자) + 토큰 상한.
  - 빔/탐욕/온도 등 기본 파라미터 프리셋 제공, 고급 설정은 숨김.

- 에러/복구
  - 모델 자산 손상/부분 다운로드 시 재시도 및 부분 무효화.
  - OOM/탭 메모리 압박 시 가벼운 프리셋으로 자동 전환.

참고 패턴: `registry/react-good-pattern.md`, `registry/react-hook-form-pattern.md`.

## 2) PWA·오프라인

- 앱 셸 캐싱
  - Service Worker 설치 시 프리캐시: 핵심 라우트, 정적 자산, 폰트.
  - 오프라인 라우팅(네트워크 불가 시 캐시 우선) 및 404/오프라인 페이지.
  - SW 헬퍼 경로: `@/shared/lib/sw-client` (브라우저 메시징/프리페치).
  - SW 계약·상수: `@/shared/config/pwa` (CACHE, PATHS, MESSAGE 등).

- 모델/토크나이저 캐싱
  - Cache Storage + 버전 네임스페이스(`model-ko-en@vX` 등).
  - 부분 업데이트(신규 버전 백그라운드 다운로드 → “업데이트 적용” 토스트).

- 저장소 관리
  - StorageManager API로 여유 공간 확인, 대용량 다운로드 전 사용자 동의.
  - IndexedDB: 프레이즈북/최근 번역/환경설정 보관.

- 설치/매니페스트
  - 웹 앱 매니페스트(아이콘, 이름, 색상), iOS/Android PWA 설치 플로우.

참고 패턴: `registry/e2e-test-pattern.md`.

## 3) UX(모바일 우선)

- 주요 화면
  - 번역 화면: 입력/출력, 언어쌍 선택, 방향 전환(Swap), 복사/클리어.
  - 모델 상태/오프라인 배지, 다운로드 진행률, Wi‑Fi 권장 경고.
  - 모드 토글: `빠른`/`정확`(설명 툴팁 포함), 길이 초과 경고.

- 프레이즈북(오프라인)
  - 카테고리(인사/길찾기/음식/쇼핑/긴급) + 즐겨찾기.
  - IndexedDB 저장, 내보내기/가져오기(옵션).

- 접근성/국제화
  - 한/영 UI 최소 지원, 키보드 탐색, 명도 대비, 라이트/다크 테마.

참고 패턴: `registry/ui-ux-guidelines.md`(존재 시), `registry/modern-and-good-design.md`.

## 4) 하이브리드 업스케일(선택)

- 서버 연동 정책
  - 기본은 로컬 추론. 온라인 업스케일은 명시적 Opt‑in(토글/1회 동의).
  - 개인정보/문장 데이터 전송 고지, 취소/타임아웃/재시도(지수 백오프).

- 품질 기준
  - 장문/문맥 유지 요청에 한정 라우팅, 실패 시 즉시 로컬로 폴백.

## 5) 성능·호환·보안

- 성능
  - 코드 스플리팅/지연 로드, 모델 방향별 번들 분리.
  - 첫 토큰 < 0.9s(WebGPU 가속 기준), 단문 완성 < 2–4s 목표.

- 호환
  - WebGPU 기능 감지 → 가속, 미지원은 WASM 유지.
  - 저사양 기기 자동 다운시프트(빔 축소/토큰 상한 감소).

- 보안/프라이버시
  - 텍스트 기본 비전송, 로컬 처리 원칙. 로그 최소화, PII 저장 금지.
  - Service Worker 스코프 제한, 정적 자원 무결성(SRI/해시) 적용.

## 6) 관측/지표(Opt‑in)

- 로컬 우선 간단 지표(비식별)
  - 번역 지연, 캐시 적중률, 모델 다운로드 성공률.
  - PWA 설치율/오프라인 세션 비율/프레이즈북 사용률.

- 오류 리포트(선택)
  - 치명적 오류만 집계, 세션/원문 텍스트 미수집.

## 7) 테스트·품질 게이트

- 단위/통합
  - 모델 로더, 백엔드 선택, 폴백 로직, 캐시 버전 스위칭 테스트.

- E2E(주요 시나리오)
  - 오프라인 첫 실행 불가 → 온라인 모델 다운로드 → 재기동 오프라인 번역.
  - WebGPU 지원 단말과 미지원 단말의 지연 차이 확인.
  - 길이 제한/모드 토글/프레이즈 저장/복구.

- 비기능 테스트
  - 저장공간 부족/네트워크 단절/다운로드 중단 재개.

참고 패턴: `registry/e2e-test-pattern.md`, `registry/test-driven-development-guide.md`.

## 8) 설정/정책

- 기능 플래그
  - 온라인 업스케일, 프레이즈북 확장, 실험적 WebGPU 튜닝.

- 사용자 설정
  - 기본 언어쌍/모드/자동 복사/텍스트 정리 옵션.

- [ ] 모델/토크나이저 프리패치·버전 교체·복구 동작.
- [ ] WebGPU 가속 가능 단말에서 배지 표기 및 체감 개선.
- [ ] 저장소/공간 안내, 대용량 경고 및 사용자 동의 플로우.
